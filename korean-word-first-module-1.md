# Korean, Word-First — Module 1: From Letters to Your First Sentences

The whole idea of this course is the opposite of what Duolingo does to you: learn the **bricks** (words) first, then the tiny bit of **glue** (particles + one verb ending), then snap them into sentences. By the end of this module you'll be able to *build* sentences yourself out of words you actually know — not just recognize memorized phrases.

**How to use this:** Work top to bottom. If you already read Hangul, skip Part 1 and start at Part 2. Say each word out loud. Romanization is training wheels — stop leaning on it the moment the Hangul clicks.

---

## Part 1 — Hangul (the alphabet)

Korean isn't written letter-by-letter in a line. Letters are packed into **syllable blocks**, always starting with a consonant and containing at least one vowel. Learn the letters, learn how blocks stack, and you can read.

### Core consonants

| Letter | Sound | Notes |
|--------|-------|-------|
| ㄱ | g / k | soft, between English g and k |
| ㄴ | n | |
| ㄷ | d / t | |
| ㄹ | r / l | a single flap, between r and l |
| ㅁ | m | |
| ㅂ | b / p | |
| ㅅ | s | |
| ㅇ | (silent) / ng | silent at the *start* of a block, "ng" at the *end* |
| ㅈ | j | |
| ㅎ | h | |

**Aspirated** (add a puff of air): ㅋ k, ㅌ t, ㅍ p, ㅊ ch
**Tense** (tight, sharp): ㄲ kk, ㄸ tt, ㅃ pp, ㅆ ss, ㅉ jj

### Core vowels

| Letter | Sound | Like |
|--------|-------|------|
| ㅏ | a | f**a**ther |
| ㅓ | eo | s**o**n / **u**p (open "aw") |
| ㅗ | o | g**o** |
| ㅜ | u | m**oo**n |
| ㅡ | eu | g**oo**d, but lips unrounded |
| ㅣ | i | mach**i**ne |
| ㅐ / ㅔ | ae / e | b**e**d (these two sound the same for most speakers now) |

Add a little "y" with an extra stroke: ㅑ ya, ㅕ yeo, ㅛ yo, ㅠ yu.

### How blocks work

Read left-to-right, top-to-bottom inside the block:

- ㄴ + ㅏ → **나** (na) — "I / me"
- ㅁ + ㅜ + ㄹ → **물** (mul) — "water" (bottom consonant is called the *받침*, batchim)
- ㅂ + ㅏ + ㅂ → **밥** (bap) — "food / rice"
- ㅅ + ㅏ + ㄹ + ㅏ + ㅁ → **사람** (sa-ram, two blocks) — "person"

That's genuinely most of what you need to start reading. Practice by sounding out every Korean word in Part 2.

## Part 3 — The glue (minimum grammar to combine words)

Korean sentence order is **Subject – Object – Verb**. "I water drink," not "I drink water." Three small things make it work.

### 1. Topic / subject particles: 은/는 and 이/가

These attach to the noun that's doing the action. Which form you use depends on whether the word ends in a consonant (받침) or a vowel:

- **Topic (은/는)** — "as for ___": ends in consonant → **은**, ends in vowel → **는**
  - 밥**은** (bap-eun), 저**는** (jeo-neun)
- **Subject (이/가)**: ends in consonant → **이**, ends in vowel → **가**
  - 사람**이** (saram-i), 친구**가** (chingu-ga)

Start with 은/는 for "I / as for me." Two irregulars to just memorize: 저 + 가 → **제가**, 나 + 가 → **내가**.

### 2. Object particle: 을/를

Marks the *thing* the action happens to. Consonant → **을**, vowel → **를**:
- 밥**을** (bap-eul), 커피**를** (keopi-reul)

### 3. Location particle: 에

"to / at" a place: 집**에** (jip-e, "to home"), 학교**에** (hakgyo-e, "to school").

### The verb ending that makes everything polite: 요

Dictionary verbs (…다) can't be used as-is. The everyday polite form is the **-요 (yo)** ending. The rule: drop 다, then —
- if the last stem vowel is ㅏ or ㅗ → add **아요**
- otherwise → add **어요**
- any 하다 verb → becomes **해요**

| Verb | Becomes | Meaning |
|------|---------|---------|
| 먹다 | 먹어요 (meogeoyo) | eat |
| 마시다 | 마셔요 (masyeoyo) | drink |
| 가다 | 가요 (gayo) | go |
| 오다 | 와요 (wayo) | come |
| 보다 | 봐요 (bwayo) | see |
| 하다 | 해요 (haeyo) | do |
| 공부하다 | 공부해요 (gongbuhaeyo) | study |
| 좋아하다 | 좋아해요 (joahaeyo) | like |
| 있다 | 있어요 (isseoyo) | there is / have |
| 없다 | 없어요 (eopseoyo) | there isn't / don't have |
| 좋다 | 좋아요 (joayo) | is good |
| 맛있다 | 맛있어요 (masisseoyo) | is delicious |

That's the whole glue kit. Now watch the bricks snap together.

## Part 4 — Building sentences (only words you already know)

**Formula: [Topic]는/은 + [Object]을/를 + [Verb]요**

| Korean | Rom. | English |
|--------|------|---------|
| 저는 물을 마셔요. | jeoneun mureul masyeoyo | I drink water. |
| 저는 밥을 먹어요. | jeoneun babeul meogeoyo | I eat (food). |
| 저는 커피를 좋아해요. | jeoneun keopireul joahaeyo | I like coffee. |
| 저는 한국어를 공부해요. | jeoneun hangugeoreul gongbuhaeyo | I study Korean. |
| 친구가 학교에 가요. | chinguga hakgyoe gayo | My friend goes to school. |
| 저는 집에 가요. | jeoneun jibe gayo | I'm going home. |
| 물이 있어요. | muri isseoyo | There's water. / I have water. |
| 시간이 없어요. | sigani eopseoyo | There's no time. / I don't have time. |
| 밥이 맛있어요. | babi masisseoyo | The food is delicious. |
| 친구가 물을 마셔요. | chinguga mureul masyeoyo | My friend drinks water. |

**Asking questions is free.** In the -요 style, a question looks identical to a statement — you just raise your pitch at the end (and write a ?).
- 커피를 좋아해요? — "Do you like coffee?"
- 밥 먹어요? — "Are you eating?" (particles are often dropped in casual speech)

### A few survival phrases to bank now
| Korean | Meaning |
|--------|---------|
| 안녕하세요 | Hello |
| 감사합니다 | Thank you (formal) |
| 고마워요 | Thanks (casual-polite) |
| 네 / 아니요 | Yes / No |
| 저는 [이름]이에요 | I'm [name] |

## Part 5 — Practice

Cover the right column and translate. Then flip it: read the English and build the Korean yourself.

1. I drink coffee. → 저는 커피를 마셔요.
2. My friend eats food. → 친구가 밥을 먹어요.
3. I go to school. → 저는 학교에 가요.
4. There's no water. → 물이 없어요.
5. I study Korean. → 저는 한국어를 공부해요.
6. The coffee is good. → 커피가 좋아요.
7. I like my friend. → 저는 친구를 좋아해요.
8. Do you have time? → 시간이 있어요?

If you can do all eight without peeking, you've proven the point: word-first works fine in Korean.
