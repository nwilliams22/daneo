# Korean, Word-First — Module 12: Getting Around

You've had 버스, 지하철, and 택시 since Module 6 — now you get the whole transit system: transfers, exits, fares, the last train home, and the sentences that steer a taxi. The grammar garnish is **-(으)러 가다** — going somewhere *in order to* do something — which is how half of all movement gets explained.

> **Warm-up (Module 11):** build these out loud — Module 11 blocks, but sentences you've never seen, which is the point: *It's snowing now* (지금 눈이 와요) · *Spring is very warm* (봄은 아주 따뜻해요) · *The wind blew yesterday* (어제 바람이 불었어요). If the blocks don't snap together, visit Review first.

**How to use this:** Half these sentences are field scripts, like Module 9's — the taxi lines and subway questions work verbatim. The other half demonstrate the course rule that's now enforced by the validator: old machinery, always-new sentences.

## Part 1 — The system, in words you mostly own

Korean transit vocabulary is honest compounding, and you already hold the parts:

- **지하철** = 지하 (underground — now official) + 철 (rail)
- **정류장** = where the bus 서요 (stops) — the 장 (place) also in 주차장 (parking place)
- **갈아타다** = switch + ride — *transfer*
- **막차** = last + vehicle — the night's real deadline (gap deck)
- **교통카드** = 교통 (transit) + M9's 카드 — the tap-everywhere T-money card
- **서울역** = Seoul + station — pronounced 서울력, a live sound-interlude exhibit

New machinery worth naming: **번** (the number-counter: 삼 번 출구, exit 3; 몇 번 버스, which bus) and **기사님** — how you address every driver (gap deck explains the title system).

## Part 3 — The glue

### 1. -(으)러 가다 — go (in order) to

Purpose rides in front of a motion verb. Vowel stem + **러**, consonant stem + **으러**:

- 표를 **사러** 가요 — I'm going to buy a ticket
- 점심을 **먹으러** 나가요 — I'm heading out to eat lunch
- 친구를 **만나러** 공항에 가요 — I'm going to the airport to meet a friend

Motion verbs only (가다, 오다, 나가다…) — for everything else, purposes wait for later modules.

### 2. The navigation question set

All old machinery, aimed at the street:

- [place]에 **어떻게 가요?** — how do I get to…? (M10's 어떻게)
- 시간이 **얼마나 걸려요?** — how long does it take? (M11's 얼마나 + new 걸리다)
- **몇 번** 버스예요? — which bus number? (M5's 몇 + new 번)

### 3. Taxi register

Everything the back seat requires: **기사님** + destination + M9's do-for-me machine — [place]로 가 주세요 · 여기서 **세워 주세요** (여기서 = 여기에서, worn smooth by speech).

## Part 4 — Building sentences

**Spot the recycling rule at work:** 눈이 오니까 조심하세요 runs Module 11's weather through Module 10's -(으)니까 — the same machinery as 비가 오니까 택시를 탑시다, deliberately never the same sentence.

::sentences::

**Subway announcement bingo:** 다음 역은… (the next station is…) · 갈아타세요 (transfer) · 내리세요 (exit). You now understand the voice in the ceiling.

## Part 5 — Practice

Cover the right column and translate; then flip and build the Korean.

1. How do I get to Seoul Station? → 서울역에 어떻게 가요?
2. How long does it take? → 시간이 얼마나 걸려요?
3. Transfer at the next station. → 다음 역에서 갈아타세요.
4. Go out exit 3. → 삼 번 출구로 나가세요.
5. Driver, please stop here. → 기사님, 여기서 세워 주세요.
6. I'm going to the airport to meet a friend. → 친구를 만나러 공항에 가요.
7. I missed the bus. So I was late. → 버스를 놓쳤어요. 그래서 늦었어요.
8. It's snowing, so be careful. → 눈이 오니까 조심하세요.

Route drill: narrate your actual commute — what you ride, where you transfer, how long it takes. Three sentences of pure recycled machinery.
