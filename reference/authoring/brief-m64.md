**Theme:** the institution's verb-and-noun set — how Korean names
rules, roles, and the bureaucratic verbs that walk those rules through:
apply, approve, violate, submit, discuss, exchange. Two spines:
(1) the rule nouns (자격 / 제한 / 위반 / 명령 / 신청 / 선택 / 신용 /

인구 / 대기업 / 외교 / 교류).

**Organizing machines:**
1. **The rule ladder (명령 → 허용 → 위반):** the boss says a thing
   (명령 — the order you can't ignore), then the institution lets it
   happen (허용하다 — the permission), then the person does what they
   do with it (시도하다 / 적용하다), then if they cross the line the
   violation fires (위반). One axis: command → permission → breach.
2. **The application axis (신청 → 등록 → 제출 → 확인 → 전달):**
   the five-step chain a learner runs when talking to a government
   office: file it, register it, submit it, confirm it, get it passed
   on. Each verb slots into the chain.
3. **The people-and-places nouns:** 근로자 (worker), 청년 (youth —
   verify M18's 청년 if taught), 인구 (population), 대기업 (big firm —
   M10's 대 + M51's 기업 — verify), 외교 (diplomacy — verify M44's
   외교관 if taught), 교류 (exchange — verify M43's 교류), 신용
   (credit — the 신 family — radar vs M1's 신 god), 자격 (the
   qualification — M55's 적? verify — 자격이 없어요 = no clearance),
   제한 (the limit — the 제 factory), 선택 (the choice — verify M22's
   선택 owner), 강제 (the coercion — the 강 family), 교환 (the
   exchange — verify M38's 교환), 등록 (the register — verify M15's
   등록), 확인 (the confirm — verify M22's 확인).
4. **The decision verbs:** 반대하다 (oppose — verify M39's 반대),
   논의하다 (discuss), 허용하다 (permit), 권하다 (advise — the 권
   factory — radar vs M12's 권 the right), 시도하다 (attempt),
   적용하다 (apply the rule).
5. **The motion verbs of the institution:** 전달하다 (relay),
   담당하다 (be in charge of), 진행하다 (advance), 참석하다 (attend),
   근무하다 (work the shift), 활동하다 (be active), 경험하다
   (experience), 제출하다 (submit).
