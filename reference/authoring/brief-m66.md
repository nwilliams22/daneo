# Brief — M66 "Push, Pour, Run" (order 75, ring 2, band 6)

Read SHARED-BRIEF.md first; follow exactly. Band 6: garnish-free.

**Theme:** the physical-action verb family — the verbs that move the
hand, foot, or body through space: point, poke, pour, spill, flick,
run, flee, follow, drop, shake, layer, flip, fire. Five clusters,
all native Korean roots.

**Organizing machines:**
1. **The point-and-reach axis:** 가리다 (block-the-view — the view
   blocker), 가리키다 (point-at — the pointing finger), 찌르다
   (poke — the needle-in verb), 집다 (pick-up — the fingers-in
   verb), 줍다 (gather — the ground-pick verb), 건지다 (lift-out —
   the lift-from-the-water verb), 비키다 (move-aside — the
   shift-it-over verb), 메다 (hang/scoop — the hand-loop verb).
2. **The pour-and-spread axis:** 붓다 (pour — the liquid-pour verb;
   radar vs M20's 붓 the toothbrush if taught), 흘리다 (spill —
   the run-out verb), 쏟아다 (spill-over — the overflow verb),
   쏘다 (fire/point — the laser-gun verb; also the "send a look"
   reading), 차다 (kick — the foot-swing verb), 밟다 (step-on —
   the ground-tread verb), 두드리다 (knock — the 두드 factory —
   the knock-on verb).
3. **The burst-and-drop axis:** 터뜨리다 (explode-open — the 터
   factory — the burst-open verb), 떨어뜨리다 (drop — the 떨 +
   뜨리다 causative — make-it-fall), 뛰어오다? no — skip,
   stay with the burst family.
4. **The run-and-chase axis:** 달려가다 (run-to — the 달려 +
   가다 compound), 달려오다 (run-from — the 달려 + 오다
   compound), 따라가다 (follow-to — the 따라 + 가다 compound),
   따라오다 (follow-from — the 따라 + 오다 compound),
   달아나다 (flee — the 달 + 아 + 나다 compound),
   도망가다 (run-away — the 도망 family; verify M36's 도망 if
   taught), 돌려주다 (return — the 돌려 + 주다 compound).
5. **The turn-and-layer axis:** 뒤집다 (flip — M19's 뒤 + 집다 —
   the over-turn verb — payoff on M19's 뒤), 털다 (shake — the 털
   factory — the shake-off verb; radar vs M10's 털 the fur, frozen),
   얹다 (put-on-top — the 얹 factory — the layer-verb; radar vs
   M30's 얹 if taught), 몰다 (push — the crowd-push verb; the
   also-flock sense; verify M40's 몰 if taught).
